### Dettaglio Tasto per Tasto (Dall'alto verso il basso, da sinistra a destra)

#### Riga 1: Tasti Funzione e Multimediali (tasti ovali piccoli)

* **`esc`**: Tasto Escape.
* **`*1 / F1`**: Bluetooth 1 (tasto giallo) / F1.
* **`*2 / F2`**: Bluetooth 2 (tasto giallo) / F2.
* **`*3 / F3`**: Bluetooth 3 (tasto giallo) / F3.
* **`F4 / 🏠`**: Tasto Home.
* **`F5 / ⧉`**: App Switcher / Multitasking.
* **`F6 / ≡`**: Menu contestuale.
* **`F7 / ⮌`**: Indietro.
* **`F8 / |◄◄`**: Traccia precedente.
* **`F9 / ►/II`**: Play / Pausa.
* **`F10 / ►►|`**: Traccia successiva.
* **`F11 / 🔇`**: Muto (icona altoparlante barrato).
* **`F12 / 🔉`**: Volume Giù.
* **`ins / 🔊`**: Volume Su / Insert.
* **`canc`**: Cancella (Delete)

#### Riga 2: Numeri e Simboli

* **`\ |`**: Backslash / Pipe (Barra verticale).
* **`! 1`**: Punto esclamativo / Uno.
* **`" 2`**: Virgolette / Due.
* **`£ 3`**: Simbolo Sterlina / Tre.
* **`$ 4`**: Simbolo Dollaro / Quattro.
* **`% 5`**: Simbolo Percentuale / Cinque.
* **`& 6`**: E commerciale (Ampersand) / Sei.
* **`/ 7`**: Barra (Slash) / Sette.
* **`( 8`**: Parentesi tonda aperta / Otto.
* **`) 9`**: Parentesi tonda chiusa / Nove.
* **`= 0`**: Segno di Uguale / Zero.
* **`? '`**: Punto interrogativo / Apostrofo.
* **`^ ì`**: Accento circonflesso / i con accento grave.
* **`back`**: Backspace (cancella a sinistra).

#### Riga 3: Lettere (Fila Superiore QWERTY)

* **`tab`**: Tasto Tabulazione.
* **`Q`**, **`W`**
* **`E €`**: Lettera E / Simbolo Euro.
* **`R`**, **`T`**, **`Y`**, **`U`**, **`I`**, **`O`**, **`P`**
* **`é è [`**: e con accento acuto / e con accento grave / Parentesi quadra aperta.
* **`* + ]`**: Asterisco / Segno Più / Parentesi quadra chiusa.
* **`invio`**: Tasto Invio (Enter - forma a L rovesciata standard ISO, si estende sulla riga inferiore).

#### Riga 4: Lettere (Fila Centrale/Home)

* **`bloc maiusc`**: Caps Lock (Blocca Maiuscole).
* **`A`**, **`S`**, **`D`**, **`F`**, **`G`**, **`H`**, **`J`**, **`K`**, **`L`**
* **`ç ò @`**: c con cediglia / o con accento grave / Chiocciola.
* **`° à #`**: Simbolo del grado / a con accento grave / Cancelletto (Hashtag).
* **`§ ù`**: Simbolo di paragrafo / u con accento grave.
* *(Parte inferiore del tasto **`invio`**)*

#### Riga 5: Lettere (Fila Inferiore)

* **`maiusc`**: Tasto Shift sinistro.
* **`> <`**: Maggiore / Minore.
* **`Z`**, **`X`**, **`C`**, **`V`**, **`B`**, **`N`**, **`M`**
* **`; ,`**: Punto e virgola / Virgola.
* **`: .`**: Due Punti / Punto.
* **`_ -`**: Trattino basso (Underscore) / Trattino (Meno).
* **`maiusc`**: Tasto Shift destro (più lungo).

#### Riga 6: Modificatori, Spazio e Frecce Direzionali

* **`ctrl`**: Control sinistro.
* **`fn`**: Tasto Function.
* **`start / alt opt`**: Tasto Start (Windows) / Alt - Option (Mac).
* **`alt / cmd ⌘`**: Tasto Alt (Windows) / Command (Mac).
* **`[ Barra Spaziatrice ]`**
* **`alt gr / cmd ⌘`**: Alt Gr (Windows) / Command (Mac).
* **`ctrl / alt opt`**: Control destro (Windows) / Alt - Option (Mac).
* **`◀`**: Freccia Sinistra.
* **`▲` / `▼**`: Freccia Su / Freccia Giù (due tasti sottili impilati nello spazio di un tasto normale).
* **`▶`**: Freccia Destra.
