# Rappresentazione Tastiera MacBook Pro M3 (Layout USA)

Ecco la mappatura completa e dettagliata tasto per tasto della tastiera integrata del MacBook Pro M3 (layout Americano QWERTY), basata sull'immagine fornita.

## Dettaglio Tasto per Tasto

### Riga 1: Tasti Funzione (Touch Bar / F-Keys)

* **`esc`**: Tasto Escape.
* **`F1 / 🔅`**: Diminuisci Luminosità Schermo.
* **`F2 / 🔆`**: Aumenta Luminosità Schermo.
* **`F3 / Mission Control`**: Icona con 3 rettangoli (Mission Control).
* **`F4 / 🔍`**: Ricerca Spotlight (lente d'ingrandimento).
* **`F5 / 🎤`**: Dettatura vocale / Siri (microfono).
* **`F6 / 🌙`**: Non disturbare (luna).
* **`F7 / |◄◄`**: Traccia precedente.
* **`F8 / ►/II`**: Play / Pausa.
* **`F9 / ►►|`**: Traccia successiva.
* **`F10 / 🔇`**: Muto.
* **`F11 / 🔉`**: Volume Giù.
* **`F12 / 🔊`**: Volume Su.
* **`[Touch ID]`**: Pulsante di accensione con sensore di impronte digitali Touch ID (tasto nero liscio all'estrema destra).

### Riga 2: Numeri e Simboli

* **`~ \``**: Tilde / Accento grave (Backtick).
* **`! 1`**: Punto esclamativo / Uno.
* **`@ 2`**: Chiocciola / Due.
* **`# 3`**: Cancelletto / Tre.
* **`$ 4`**: Dollaro / Quattro.
* **`% 5`**: Percentuale / Cinque.
* **`^ 6`**: Accento circonflesso / Sei.
* **`& 7`**: E commerciale (Ampersand) / Sette.
* **`* 8`**: Asterisco / Otto.
* **`( 9`**: Parentesi tonda aperta / Nove.
* **`) 0`**: Parentesi tonda chiusa / Zero.
* **`_ -`**: Trattino basso (Underscore) / Trattino (Meno).
* **`+ =`**: Segno Più / Segno di Uguale.
* **`delete`**: Tasto Cancella (Backspace).

### Riga 3: Lettere (Fila Superiore QWERTY)

* **`tab`**: Tasto Tabulazione.
* **`Q`**, **`W`**, **`E`**, **`R`**, **`T`**, **`Y`**, **`U`**, **`I`**, **`O`**, **`P`**
* **`{ [`**: Parentesi graffa aperta / Parentesi quadra aperta.
* **`} ]`**: Parentesi graffa chiusa / Parentesi quadra chiusa.
* **`| \`**: Pipe (Barra verticale) / Backslash.

### Riga 4: Lettere (Fila Centrale/Home)

* **`caps lock`**: Tasto Blocca Maiuscole (con indicatore LED).
* **`A`**, **`S`**, **`D`**, **`F`**, **`G`**, **`H`**, **`J`**, **`K`**, **`L`**
* **`: ;`**: Due punti / Punto e virgola.
* **`" '`**: Virgolette (doppi apici) / Apostrofo (singolo apice).
* **`return`**: Tasto Invio (forma orizzontale ANSI standard).

### Riga 5: Lettere (Fila Inferiore)

* **`shift`**: Tasto Shift sinistro.
* **`Z`**, **`X`**, **`C`**, **`V`**, **`B`**, **`N`**, **`M`**
* **`< ,`**: Minore / Virgola.
* **`> .`**: Maggiore / Punto.
* **`? /`**: Punto interrogativo / Barra (Slash).
* **`shift`**: Tasto Shift destro.

### Riga 6: Modificatori, Spazio e Frecce Direzionali

* **`fn 🌐`**: Tasto Function / Cambio lingua (Globo).
* **`control ^`**: Tasto Control sinistro.
* **`option ⌥`**: Tasto Option (Alt) sinistro.
* **`command ⌘`**: Tasto Command sinistro.
* **`[ Barra Spaziatrice ]`**
* **`command ⌘`**: Tasto Command destro.
* **`option ⌥`**: Tasto Option (Alt) destro.
* **`◀`**: Freccia Sinistra.
* **`▲` / `▼`**: Freccia Su / Freccia Giù (due tasti sottili impilati nello spazio di un tasto normale).
* **`▶`**: Freccia Destra.
